# Landmark Position and Binaural Turn Cues
Jinjie Zhao, SID 540895948

This project compares binaural cue trajectories across 12 landmark bearings and three distances, using matched head-fixed controls. The results describe the generated signals. No listener study was performed.

- [Final report](ELEC5305_Report.pdf)
- [Video demonstration](project_video.mp4)
- [Download code and data](https://github.com/JinJieee/elec5305-project-540895948/archive/refs/heads/main.zip)

Open the downloaded project folder in MATLAB and run `run_project.m`. Run `play_demo` for the animated listening comparisons.
