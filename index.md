# ELEC5305 Project

## Design and Evaluation of Spatial Auditory Landmarks for Turn Perception in Audio-Only Virtual Reality

This project investigates how the spatial placement of auditory landmarks affects perceived turn direction and auditory vection in an audio-only virtual environment.

MATLAB will be used to prepare and objectively verify the auditory stimuli. Unity and Wwise will be used to implement and evaluate the spatial-audio system.
